📘 JavaScript Complete Academy Notes

Chapter 1: JavaScript Fundamentals

JavaScript: JavaScript is a high-level, interpreted programming language used to create dynamic and interactive web applications.
console.log("Welcome to JavaScript");
Variables: Variables are used to store data values that can be reused and changed.
let name = "Ahmed"; const age = 21; var city = "Karachi";
Data Types: JavaScript data types define the kind of value stored in a variable.
let text = "Hello"; // String let num = 10; // Number let active = true; // Boolean let value = null; // Null let x; // Undefined
Operators: Operators perform operations on values.
let a = 10, b = 3; console.log(a + b); // Arithmetic console.log(a > b); // Comparison console.log(a && b); // Logical

Chapter 2: Control Flow

if / else: Used to execute code based on conditions.
let marks = 75; if(marks >= 50){ console.log("Pass"); } else { console.log("Fail"); }
Loops: Loops repeat code until a condition becomes false.
for(let i = 1; i <= 5; i++){ console.log(i); }

Chapter 3: Functions

Function: A function is a reusable block of code that performs a specific task.
function greet(name){ return "Hello " + name; } console.log(greet("Ali"));
Arrow Function: A modern and shorter syntax for writing functions.
const add = (a, b) => a + b; console.log(add(4, 6));

Chapter 4: Arrays & Methods

Array: Arrays store multiple values in one variable.
let numbers = [1, 2, 3, 4];
Array Methods: Used to manipulate arrays.
numbers.push(5); numbers.pop();
map() & filter(): Used for transforming and selecting data.
let doubled = numbers.map(n => n * 2); let even = numbers.filter(n => n % 2 === 0);

Chapter 5: Objects

Object: Objects store data in key-value pairs.
let student = { name: "Sara", age: 20, isPass: true };
this keyword: Refers to the current object.
let user = { name: "Ali", greet(){ console.log(this.name); } }; user.greet();

Chapter 6: DOM & Events

DOM: DOM allows JavaScript to interact with HTML elements.
document.querySelector("h1").style.color = "blue";
Events: Events respond to user actions.
document.querySelector("button") .addEventListener("click", () => { alert("Clicked"); });

Chapter 7: Storage & Timing

localStorage: Stores data permanently in browser.
localStorage.setItem("name", "Ali"); console.log(localStorage.getItem("name"));
setTimeout & setInterval: Used to execute code after time delay or repeatedly.
setTimeout(() => console.log("Hello"), 2000);
